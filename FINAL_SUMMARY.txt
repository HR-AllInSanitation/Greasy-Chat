ENVIRONMENT VARIABLES REQUIRED

Set these in Vercel Project Settings → Environment Variables:

UPSTASH_REDIS_REST_URL
  Description: Redis database URL (for state storage)
  Example: https://***-rest-redis.upstash.io

UPSTASH_REDIS_REST_TOKEN
  Description: Redis authentication token
  Example: AYH...

QSTASH_TOKEN
  Description: QStash authentication token (for async email scheduling)
  Example: eyJ0eXA...

QSTASH_CURRENT_SIGNING_KEY
  Description: Key for verifying QStash webhook signatures
  Example: sig_...

HQ_EMAIL_DELAY_SECONDS
  Description: Delay before HQ email is sent (default: 120)
  Example: 120

RESEND_API_KEY
  Description: Resend API key (for sending emails)
  Example: re_...

GOOGLE_SHEETS_WEBHOOK_URL
  Description: Google Sheets webhook URL
